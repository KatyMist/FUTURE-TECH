## Возможности · Features

| Русский | English |
|---|---|
| **Адаптивная вёрстка** — `rem` и «резиновые» размеры через SCSS-функции `rem()` и `fluid()` | **Responsive layout** — `rem` units and fluid sizes via the `rem()` and `fluid()` SCSS functions |
| **Мобильное меню** — бургер-кнопка с оверлеем | **Mobile menu** — burger button with an overlay |
| **Табы** — переключение категорий на главной, в новостях и ресурсах | **Tabs** — category switching on the Home, News and Resources pages |
| **Видеоплеер** с собственными кнопками воспроизведения | **Video player** with custom play controls |
| **Раскрывающийся контент** — кнопка «Read Full Blog» | **Expandable content** — a "Read Full Blog" button |
| **Кастомный селект** — выбор кода страны в форме | **Custom select** — country code picker in the form |
| **Маска ввода телефона** в форме обратной связи | **Phone input mask** in the feedback form |
| **Доступность**: семантическая разметка, `aria`-атрибуты | **Accessibility**: semantic markup, `aria` attributes |
| **БЭМ и компоненты** — каждый блок в своём SCSS-файле, каждый JS-компонент — отдельный класс | **BEM and components** — every block has its own SCSS file, every JS component is a separate class |

## Запуск локально · Running Locally

```bash
git clone https://github.com/KatyMist/future-tech.git
cd future-tech
npm install           # установить Sass · install Sass
npm run sass-watch    # компиляция SCSS → CSS · compile SCSS → CSS (watch mode)
```

> [!TIP]
> Откройте `index.html` через локальный сервер (например, **Live Server** в VS Code): JS подключён как ES-модуль и не работает при открытии файла напрямую (`file://`).
>
> Open `index.html` through a local server (e.g. **Live Server** in VS Code): the JS is loaded as an ES module and won't run from `file://`.
